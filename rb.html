Redbubble の出品

無料。画像をアップして文を貼るだけ。売れたら Redbubble が作って送ってくれる

① 最初だけ（5分）

  1. redbubble.com で「Sign up」→ 親の名義でアカウントを作る（お金の受け取りも親の PayPal か口座）
  2. ショップ名の例：SoraKanji
  3. 右上のアイコン → Add New Work が出品の画面

② 1つずつ出品（1つ2〜3分）

  1. 「画像を保存」→ Add New Work で、その画像を選ぶ
  2. Title・Tags・Description を「コピー」して貼る
  3. 商品は全部オンのまま。Default product は Sticker、Media は Digital art
  4. 「Is this work mature?」は No → 権利のチェックに ✓ → Save Work

背景は透明。デザインは黒・赤・紺なので、白や明るい色の商品で映えます（黒いTシャツはオフにしてOK）。
